# Dentist Landing Page

Ayollar va bolalar uchun mo'ljallangan zamonaviy, minimalistik stomatolog landing page. Sahifa gul elementlari, pastel ranglar, bolalar uchun original multfilm-uslubidagi maskotlar, xizmatlar, shifokor haqida ma'lumot, afzalliklar, oldin/keyin natijalar, mijozlar fikrlari, narxlar va Telegram bot/kanal CTA tugmalarini o'z ichiga oladi.

## Ishga tushirish

Loyihani lokal ko'rish uchun oddiy statik serverdan foydalaning:

```bash
python3 -m http.server 4173
```

So'ng brauzerda `http://localhost:4173` manzilini oching.

## Moslash

- `index.html` ichidagi `https://t.me/your_dental_bot` va `https://t.me/your_dental_channel` havolalarini haqiqiy Telegram havolalariga almashtiring.
- Shifokor ismi, telefon raqami, klinika manzili va narxlarni real ma'lumotlar bilan yangilang.
- Before/after bloklariga ruxsat olingan haqiqiy suratlarni joylashtiring.
- Agar real bolalar uchun personajlar qo'shilsa, mualliflik huquqi bilan himoyalangan mashhur multfilm qahramonlari o'rniga klinika uchun original maskotlardan foydalaning.
